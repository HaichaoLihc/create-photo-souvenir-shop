# Fabrication reference: actual original runtime models

Open all three images: [oblique](oblique.png), [back](back.png), [clay](clay.png).

These are real WebGL renders of `gull-key`, `lake-magnet` and `cairn-pin` from the bundled original `sculpted-crafts.js`, made with `render_review.mjs`. They contain no user photographs and are not generated product mockups. The geometry is distributed under the repository code license.

Use them as a **minimum fabrication reference**, not a catalog to copy into every trip. Notice the articulated chain and separate charm, modeled enamel/metal boundaries, stepped relief, physical thickness, recessed rear magnets and pin catch. Clay views retain the forms after texture/color removal. Choose different materials and construction when the new photos suggest them; match the care, not the bird, mountain or stone motifs. The new collection must still improve on weak shapes and be judged at room scale as well as this close-up scale.
